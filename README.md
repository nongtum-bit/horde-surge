# Horde Surge

เกมแนว Vampire Survivors / horde survival บนมือถือ — สู้ฝูงศัตรู, เก็บอาวุธ, อัพเกรดตอนเลเวลอัพ, ล่าบอส

**เล่นเลย:** [nongtum-bit.github.io/horde-surge](https://nongtum-bit.github.io/horde-surge/)

## วิธีเล่น

- เดินด้วย **WASD / ลูกศร** หรือ **จอยสติ๊ก** มุมซ้ายล่าง
- อาวุธยิงอัตโนมัติ เล็งศัตรูใกล้สุดเอง
- เก็บ XP เขียว → เลเวลอัพแล้วเลือกสกิล (ยิงรัว / คล่องตัว / ดาเมจ / เลือด / แม่เหล็ก / คริ ฯลฯ)
- เปิดลังอาวุธในด่านเพื่อใส่ปืนเพิ่ม (สูงสุด 4 ช่อง)
- ซิปไลน์ = เดินเข้าเสาเพื่อสไลด์ข้ามหลุม
- ทอง / เพชร เอาไปปลดล็อกฮีโร่และอัปอาวุธที่หน้าโฮม

## ด่าน

1. **หุบเขาเขียว** — ปลดล็อกตั้งแต่แรก
2. **เนินทรายทรุด** — ชนะด่าน 1
3. **ปล่องเถ้า** — ชนะด่าน 2 แล้วสู้บอสไฟ

เซฟเกมอยู่ในเบราว์เซอร์ (`localStorage`) ไม่หายเมื่อรีเฟรช

ถ้าเปิดลิงก์แล้วขึ้น 404 ให้ไปที่ repo → **Settings → Pages → Deploy from branch `main` / root**
