# Horde Surge

เกมแนว horde survival + พาร์กัวร์ 2.5D — กระโดด ปีนเขา เก็บปืนบนแมพ เปิดกล่องสมบัติ ล่าบอส

**เล่นเลย:** https://nongtum-bit.github.io/bomberman/horde-surge/

## วิธีเล่น

- เดินด้วย **WASD / ลูกศร** หรือ **จอยสติ๊ก** มุมซ้ายล่าง
- **เว้นวรรค** หรือปุ่ม **กระโดด** มุมขวา — กระโดดข้ามศัตรู / หลุม / ขึ้นหน้าผาเตี้ย
- ชนกำแพงสูงแล้วกดกระโดด = **ปีนเขา**
- อาวุธยิงอัตโนมัติ เล็งศัตรูใกล้สุดเอง
- เก็บ XP เขียว → เลเวลอัพแล้วเลือกสกิล
- **ปืนบนแท่น** และ **กล่องสมบัติ** วางตามแมพ ให้เดินไปเก็บ
- ซิปไลน์ = เดินเข้าเสาเพื่อสไลด์ข้ามหลุม
- ทอง / เพชร เอาไปปลดล็อกฮีโร่และอัปอาวุธที่หน้าโฮม

เซฟเกมอยู่ในเบราว์เซอร์ (`localStorage`)
